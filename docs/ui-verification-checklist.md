# UI 验收清单（品牌一致性 + 目标视口）

> 依据 PRD 11.3 与 `docs/design-system-baseline.md`。合并 UI 改动前逐项自检；截图基线当前需本地手工完成（环境无浏览器自动化工具）。

## 1. 目标视口截图

每个 UI 任务合并前，至少在以下四个尺寸各截一张：

| 视口 | 用途 |
| --- | --- |
| 390 × 844 | 手机竖屏，检查溢出 / 遮挡 / 表格横向滚动 |
| 768 × 1024 | 平板，检查卡片断行与栅格 |
| 1280 × 800 | 笔记本，默认验收尺寸 |
| 1440 × 900 | 桌面，检查留白与信息密度 |

## 2. 关键页面清单

- 登录页 / 注册页
- 项目中心（列表 + 空态 + 新建弹窗 + 删除确认）
- 项目概览（五看进度 + 推荐下一步 + 旧数据迁移）
- 五看工作台（概览 / 看市场 / 看用户 / 看竞品 / 看自己 / 看/找机会）
- 各视角内嵌工具入口 + 工具页「返回项目」
- 机会卡（优先级矩阵 + 决策摘要 + 利润假设）

## 3. 品牌一致性检查项

- [ ] 主色用 indigo/violet 渐变 CTA，中性色用 Apple 灰阶（`#f5f5f7` / `#1d1d1f` / `#86868b`）
- [ ] 卡片圆角 `rounded-[20px]` / 弹窗 `rounded-[32px]`，控件 `rounded-xl`
- [ ] 组合类名用 `cn()`，不手写字符串拼接
- [ ] 下拉用 `ui/Select`，胶囊多选用 `MultiSelectChips`
- [ ] 反馈走 `sonner` toast；破坏性操作二次确认
- [ ] 空态：灰字居中 + 一句可行动提示
- [ ] 无乱码、无 Markdown 源码泄漏、表格不破裂、文字不遮挡
