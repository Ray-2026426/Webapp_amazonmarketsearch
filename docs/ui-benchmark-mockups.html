改动之后，上一条（响应式联动）会告诉你"因为你改了 X，所以机会分从 61 → 68"。
我们现在：想改需求得先切到"看用户"、再找到那块、再展开 —— 三步以上，而且切走会丢当前上下文。
借鉴后：一个快捷键直达任何"可改的东西"，改完回到原地。
