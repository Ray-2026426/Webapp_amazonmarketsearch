# 操作手册：10 分钟从零跑到机会卡

> 面向非技术同事。目标是让你在 10 分钟内走完「五看」，拿到一张**有证据、可决策**的机会卡（或者一个诚实的"没机会"结论）。
> 全程只有一个原则：**不要手填结论，先让系统取数**。你只负责拍板。
>
> 配套：想看"某个功能到底该长什么样、点哪里算通过"，用 `docs/M6-ui-acceptance-checklist.md`（对着线框图逐条点）。

---

## 0. 开始前（1 分钟）

1. 让管理员确认数据池已就绪：设置 → 管理员后台 → 环境自检，各 provider 显示"已配置"；
2. 登录（**必须登录**：平台数据池只对登录用户开放，游客只能用示例数据）；
3. 想跑真数据？准备好：一个品类（如"薄枕 thin pillow"）与 1-3 个头部 ASIN。

### 0.1 关于 AI 请求地址（想用第三方中转时才需要看）

设置 → **API 与模型** → 「API 请求地址」区域，现在会把三件事同屏写清楚：

| 你会看到 | 含义 |
| --- | --- |
| 官方地址 | 该厂商的官方 API 地址 |
| 本站默认转发到 | **留空时实际会打到的地址**。7 个供应商就是官方地址；**DeepSeek 例外，走的是第三方中转 `openrouter.fans`**（既有配置，界面会显著提示"不是官方地址"） |
| 本次实际请求 + 通道 | 这次请求真正发到哪、走哪条通道（本站同源转发 / 经本站服务端转发 / 浏览器直连） |

三种用法：
1. **用默认**（推荐）→ 地址框留空，走本站同源转发，不受浏览器跨域限制；
2. **改成官方地址** → DeepSeek 那类"默认走中转"的供应商，点「改用官方地址」即可（此后由本站服务端转发到官方站点）；
3. **接我自己的第三方中转** → 供应商选「**自定义 / 第三方中转**」，填 Base URL（如 `https://relay.example.com/v1`，只填域名也会自动补成 `/v1/chat/completions`）、模型名（按中转站给的名称）、以及中转站发的 Key。按 **OpenAI 兼容** 发送；若对方只有 Claude 原生格式，需要它自己提供 OpenAI 兼容入口。

安全与流向：自定义中转走**服务端转发**时，你的 Key 会经本站服务端一次，**不保存、不记录、不写日志**；若你的中转本身允许浏览器跨域，也可以选直连（不经服务端）。两个已知限制：转发只支持 OpenAI 兼容形态；流式输出在转发通道下会降级为一次性返回。

> 只想先看流程？点「项目中心 → 加载示例数据」，跳过 §1 的取数，直接看 §2 的五看。

## 1. 建项目 + 取数（3 分钟）

1. 项目中心 → 新建项目，填：站点、品类名、目标（新品/改版）；
2. 进项目 → 概览页点 **「开始分析」**（一键向导会按 看用户 → 看市场 → 看竞对 → 看自己 顺序跑）；
3. 如果某一步提示"缺数据"：按提示点按钮去补（市场大盘上传 Excel / 关键词工具 / 评论 VOC / 竞品工具）。
   **提示"缺数据"不是错误，是系统在告诉你缺哪一环。**

## 2. 五看：每一步你只需要看三件事（4 分钟）

| 看 | 你要确认的 | 产物在哪 |
| --- | --- | --- |
| **看用户** | 需求是不是真的（关键词证据 + 评论原文 + 覆盖 ASIN） | 需求分类树卡片下的"证据链"；搜索路径四层漏斗 |
| **看市场** | 切法合不合理 | 「市场细分方案（三选一）」→ 点开细分明细 → **选一个方案**并给 1-2 个细分点「设为目标细分」 |
| **看竞对** | 三个对标选得对不对 | 「全量 Listing 三列对比」+ 每张竞对卡的三块分析（画像/痛点矩阵/满足矩阵）+ 结论里的**赢的路径** |
| **看自己** | 我接不接得住 | 背景库六维度（不必一次填完）+ 品类选择题（每题都写了"为什么问"）+ 适配度 |
| **看机会** | 值不值得做、先做什么 | 「决策看板」：Go/No-Go 汇总 + 机会卡（评分拆解/证据/路线图/资源缺口/控制点） |

**三个必须知道的判断点**：

1. **机会卡是 AI 候选**：先「确认这张卡」再拍板（Go / 验证后进入 / 暂缓 / 放弃）。没确认的卡不会进正式结论。
2. **红条意味着什么**：卡顶出现红条 = 你的硬约束（毛利红线/认证/MOQ）没过 → 最多只能"验证后进入"，别硬冲。
3. **"没机会"是合法结果**：系统给"已判断无机会（卡在哪一环）"或"证据不足（缺什么）"。**看到这两种结论不要重跑**，先按它说的补齐或换方向。

## 3. 拍板与交付（2 分钟）

1. 给机会卡选决策（Go / 验证后进入 / 暂缓 / 放弃）→ Go/No-Go 汇总会自动更新；
2. 点「导出 HTML 审核报告」或「导出 MD」→ 直接发给负责人/管理层；
3. 机会卡里的**控制点**（准入/过程/止损）默认是"待确认"：点一下即可确认，未确认的会出现在导出件里标"待确认"。
   要改阈值：打开这张卡的「查看详情 → 二级页⑭」，每条控制点可以直接改数值（改完点「保存」，或点「恢复默认」回到系统推导值）。
   改过的会标「已人工修改」，同时**作废之前的「已确认」**——用户确认的是那个数字，数字变了要重新拍板；重新生成机会卡也不会覆盖你改过的阈值。

## 4. 常见卡点与处理

| 现象 | 原因 | 怎么处理 |
| --- | --- | --- |
| 四步都提示"已跳过" | 没配模型 Key 或缺数据 | 面板会分别提示：缺 Key → 去设置；缺数据 → 点按钮补数据 |
| 「抓取全字段」提示需要登录 | 决策 A：数据池只对登录用户开放 | 登录后再试，或用示例数据 |
| 细分为空 | 「看用户」还没有需求域 | 先跑看用户，或在看用户里手填 1 条需求 |
| 赢的路径是"无赢面" | 三条路径都不成立 | 看它列出的三个卡点：换细分 / 换需求 / 补能力，别在这个方向硬投 |
| 字段抓取率很低 | 外部接口只抓到部分字段 | 看"未抓取"格子的提示，可重试失败步骤；抓取率会如实反映，不伪造 |
| 控制点都是"待确认" | 系统只给默认阈值 | 逐条确认（这是拍板动作），或打开二级页⑭ 改成本品类的真实阈值（改完需重新确认；改过的不怕重算覆盖） |

## 5. 三条使用纪律（重要）

1. **别把 AI 的解释当结论**：AI 只解释，分数、状态、路径都是确定性算出来的；
2. **别跳过证据**：任何结论都要能点回原始来源（评论原文 / ASIN / 图表），点不回去的就别信；
3. **"没机会"要归档**：写下卡在哪一环，下次同类品类可以直接复用这个判断。
