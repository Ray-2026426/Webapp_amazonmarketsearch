# Kairo V3 开发交接包

本目录可直接发给产品、设计和开发人员。

- `index.html`：产品核心价值、目标用户、机会定义、使用方法与完整可点击 UI 原型。原型覆盖 7 个主屏、13 个二级证据页和 3 个明细工作台；点击原型内“查看完整页面目录”可逐页检查。
- `PRD.md`：完整功能需求、数据与 AI 分工、页面、数据对象、异常状态、MVP 和验收标准。
- `styles.css` / `app.js`：`index.html` 的样式和交互。

使用方法：用浏览器直接打开 `index.html`。若浏览器限制本地文件脚本，可在本目录启动任意静态 HTTP 服务器后访问。

产品口径冲突时，优先级为：

1. `PRD.md`
2. `index.html`
3. 项目 `docs/` 下的旧 PRD 和旧线框图（仅作素材参考）

本版从旧线框图恢复了主流程与 L3 明细的完整信息层级，但不恢复已经推迟到后续版本的“三定”、路线图、控制点、任务和提醒。
